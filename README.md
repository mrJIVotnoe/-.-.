# 🛥️ Journey In Vladivostok (JIV) — Аренда флота & Цифровой капитан

**Journey In Vladivostok (JIV)** — Интерактивный экосистемный маркетплейс аренды яхт, катеров, катамаранов и гидроциклов в акватории Владивостока (Залив Петра Великого, Остров Русский, Босфор Восточный, Японское море).

![JIV Fleet Banner](https://images.unsplash.com/photo-1540962351504-03099e0a754b?auto=format&fit=crop&w=1200&q=80)

---

## 🚀 Основной функционал платформы

1. **⚓ Интерактивная морская карта Владивостока:**
   - Отображение изобат глубин, судоходных фарватеров и опасных мелей.
   - GPS-трекинг судов в реальном времени (AIS-синхронизация).
   - Интерактивный конструктор маршрутов с возможностью визуализации собственного морского пути.

2. **🌊 Модуль «Цифровой Капитан» (Gemini AI):**
   - Умный ассистент на базе Google Gemini API для генерации уникальных экскурсионных маршрутов, рекомендации безопасных бухт с учетом ветро-волновой обстановки и расчета расхода топлива.

3. **🛥️ Капитанский мостик (Модуль судовладельцев):**
   - Публикация и управление объявлениями плавсредств.
   - Загрузка реальных фотографий судна с устройства, судовых билетов МЧС и лицензий ГИМС.
   - Система бронирования и распределения экипажей.

4. **📢 Партнёрский мостик & Рекламная сеть:**
   - Нативная интеграция рекламных баннеров и промо-кампаний с загрузкой баннеров прямо с устройства.
   - Интеграция с Национальной платёжной системой (НСПК / Мир) и СБП (Система Быстрых Платежей).

5. **🛡️ Панель безопасности & Безопасные сделки:**
   - Двухфакторная верификация капитанов и фотоконтроль лица (селфи).
   - Интеграция SOS-сигналов и связи с МЧС/ГИМС.

6. **🎨 Динамический движок тем оформления:**
   - **Автоматический режим по времени суток**:
     - ☀️ **Солнечный день** (07:00 – 18:00)
     - 🌅 **Вечерний закат** (18:00 – 22:00)
     - 🌕 **Полнолунная ночь** (22:00 – 07:00)
   - Поддержка ручного переключения в любой момент.

## 🛠️ Технологический стек

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Motion (Framer Motion)
- **Icons:** Lucide React
- **Backend / AI:** Express.js, Google GenAI SDK (@google/genai)
- **Payments & Legal:** НСПК (Мир / СБП), WeChat Pay, Stripe Corporate Global

## 🚀 Запуск и сборка проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/jiv-vladivostok-fleet.git
cd jiv-vladivostok-fleet
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Переменные окружения
Создайте файл `.env` на основе `.env.example`:
```env
GEMINI_API_KEY="ваш_ключ_gemini_api"
APP_URL="http://localhost:3000"
```

### 4. Режим разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### 5. Сборка для продакшена
```bash
npm run build
npm run preview
```
